# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussion constructive. Harassment and discrimination are not tolerated.

To report an issue with someone's conduct, contact the maintainer listed in [`CODEOWNERS`](CODEOWNERS). Reports are handled confidentially.
