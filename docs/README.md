# docs/

Project documentation for the M365 Citizen Dev Kit — plans and design notes that aren't part of the published patterns.

| Document | What it covers |
|---|---|
| [anonymization-plan.md](anonymization-plan.md) | How this kit was de-branded for publication: the Contoso naming convention, what was excluded vs. ported, the anonymization scan, and the contributor rules. |
| [RELEASING.md](RELEASING.md) | The dual-bump release procedure: changing a pattern means updating the guide, its prompt, and `versions.json` in the same commit. |
| [decisions/](decisions/) | Architecture Decision Records (ADRs) — why structural and publication decisions were made. |

## Diátaxis

As the kit's own how-to/reference docs grow, organize them by reader need: **tutorials** (learning), **how-to guides** (tasks), **reference** (lookup), **explanation** (why). Don't mix two modes in one document.
