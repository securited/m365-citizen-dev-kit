    About This App

    A Hello World application demonstrating every technique of the SharePoint App Pattern.

    What Each Tab Demonstrates

    Dashboard

    • Shell + Data Pattern — The shell .aspx holds boot logic only, with no feature code and no application state; all CSS and HTML load from hello-world_data/ via the SharePoint REST $value endpoint at boot time
    • Runtime Module Loading — The shell fetches a fixed asset list, then app.js reads manifest.json and loads each feature module (dashboard.js, messages.js, metrics.js) as a Blob-wrapped <script>. Adding a module means uploading it and adding one line to the manifest — both Contribute-level, so the shell never needs a redeploy
    • Authentication — Identity resolved via /_api/web/currentUser with graceful fallback to _spPageContextInfo when available (Site Pages only)
    • Site URL Derivation — deriveSiteUrl() extracts the site root from window.location so the app works in any document library without hardcoding
    • Microsoft Graph — Profile photo and extended profile fields fetched from /me using the session's Bearer token
    • Loading State — Animated indicator shown immediately; UI revealed only after initial data resolves
    • Error State — Inline error displayed near the affected component rather than a blocking alert

    Messages

    • List Auto-Provisioning — Detects a missing list via HTTP 404, shows a setup banner, and creates the HelloWorldMessages list plus all custom fields in one click
    • REST API CRUD — Full create, read, inline edit (PATCH/MERGE), and delete against a SharePoint list
    • Write Operations — Every mutating call fetches a fresh digest from /_api/contextinfo rather than relying on the page-injected value
    • OData Queries — $select, $orderby, and $top on every read; $skiptoken for continuation paging
    • Large List Design — Results capped with $top; a Load More button fetches the next page via $skiptoken from the __next link
    • Toast Notifications — Non-blocking, auto-dismiss confirmations after create, update, and delete
    • Destructive Confirmation — Inline confirm overlay before delete; no window.confirm()
    • Empty State — Explicit message when the list exists but contains no items
    • Safe Content Display — Message body rendered via textContent in a modal overlay, never innerHTML

    Metrics

    • JSON File as Data Source — metrics.json (~360 KB) fetched from hello-world_data/ via the $value endpoint and parsed entirely client-side
    • Large File Loading — Demonstrates loading and rendering a large JSON payload; file size and load time displayed in the footer
    • File vs. List Trade-off — Static, read-only reference data served as a file rather than a list; appropriate when no per-row querying or user writes are needed
    • Inline SVG Sparklines — 96-point history arrays rendered as <polyline> elements without any charting library
    • Threshold Coloring — Warn/critical thresholds applied per metric with inverted logic for uptime (lower = worse)
    • Loading & Error States — Spinner shown while the file fetches; error message shown on failure

    About (this tab)

    • In-Page Navigation — All four tabs are sections of the same page; showView() shows/hides them with no page loads or URL changes
    • Power Automate — HTTP trigger URL read at runtime from a restricted AppConfig list; never stored in the shell file

    File Structure

    FilePurpose
    hello-world.aspx Shell — boot logic only: derives paths, loads assets, boots app
    hello-world_data/styles.css All application styles
    hello-world_data/content.html All application markup
    hello-world_data/platform.js Shared SharePoint helpers — digest, write headers, toasts, errors, overlay, list provisioning, Power Automate. New shared helpers go here, never in the shell
    hello-world_data/app.js Configuration, the module loader, navigation, and init
    hello-world_data/manifest.json Feature modules to load, in order — the file you edit to add a feature
    hello-world_data/dashboard.js Feature module — identity and the Graph profile card
    hello-world_data/messages.js Feature module — list CRUD, paging, and first-run provisioning
    hello-world_data/metrics.js Feature module — status cards and sparklines over the JSON dataset
    hello-world_data/metrics.json Sample metrics dataset (~360 KB) for the Metrics tab

    Required SharePoint Setup

    • The HelloWorldMessages list is created automatically on first use — click "Create List" when prompted on the Messages tab
    • Optional: create a list named AppConfig with columns Title and Value to store Power Automate HTTP trigger URLs
    • Custom scripts must be enabled on the target site before uploading — open a help desk ticket to request a 24-hour deployment window
